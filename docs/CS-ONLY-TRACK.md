# GATEPath 2027 — CS-only release

## Product scope
- The only selectable/servable paper is CS — Computer Science and Information Technology.
- General Aptitude is included as its shared 15-mark section.
- Other GATE papers and their content are removed from the active catalogue.
- The website opens into a guest workspace; there is no sign-in or registration page.

## Official sources
- CS syllabus: https://gate2027.iitm.ac.in/static/doc/GATE2027_Syllabus/CS_GATE2027_Syllabus.pdf
- General Aptitude syllabus: https://gate2027.iitm.ac.in/static/doc/GATE2027_Syllabus/GA_GATE2027_Syllabus.pdf
- Paper pattern: https://gate2027.iitm.ac.in/question_paper_pattern
- Previous papers: https://gate2027.iitm.ac.in/download

## Content provenance
- Syllabus statements are transcribed/mapped from official GATE 2027 PDFs.
- Topic cards, study notes, practice items and the current full mock are GATEPath original editorial content, not official questions.
- Official PYQ papers and answer keys are linked to IIT-hosted PDFs. The 2026 interactive import contains answer-key metadata; original stems and figures are not copied into this app.

## Data durability
Guest data is stored against a random session record. Vercel preview uses `/tmp/gatepath.db`, which is ephemeral. Do not treat that preview as a durable student-record service. A durable production deployment needs managed persistent storage or the configured Render disk.
